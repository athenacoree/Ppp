# The Quiet Room — Android

Juego narrativo 2D nativo para Android, desarrollado en Kotlin y Jetpack Compose. No utiliza WebView, HTML, JavaScript, PWA ni navegador.

## Primera versión
- Prólogo interactivo en el dormitorio.
- Diálogos y decisiones.
- Personaje 2D dibujado con Canvas nativo.
- Cuatro conjuntos de ropa seleccionables.
- Guardado local del día, decisiones y vestuario.
- Workflow de GitHub Actions para compilar un APK debug.

## Compilar
Abre el proyecto en Android Studio con JDK 17 y ejecuta la tarea `assembleDebug`.

También puedes descargar el APK de prueba desde la sección **Actions** de GitHub cuando termine correctamente el workflow.
